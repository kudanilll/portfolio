## About This Portfolio

This is my personal portfolio built with **Next.js 16**. It’s a living space for my work, ideas, and experiments.
All motion is handcrafted with **GSAP** for smooth micro-interactions and delightful transitions.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Animations**: GSAP
- **Deploy**: Vercel

## Getting Started

> **Requirements:** Node.js 18.18+ or 20+, and your favorite package manager (npm/pnpm/yarn/bun).

```bash
# 1) Install deps
npm install

# 2) Start dev server
npm dev
```
